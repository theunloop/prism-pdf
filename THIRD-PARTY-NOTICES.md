## 1. Vendored crates

None. `hayro-ccitt` and `hayro-jbig2` were vendored under `vendor/` until the move to crates.io,
carrying a one-line MSRV compatibility change to `hayro-ccitt`'s `BitReader::align`. Both are now
resolved from crates.io unmodified. A `[patch.crates-io]` section does not travel with a published
crate, so the fork would have been invisible to anyone depending on `prismpdf-filters`; raising the
MSRV to 1.87 — where `usize::is_multiple_of` is stable — removed the reason for it.

## 2. Bundled assets

### 2.1 `crates/pdf-standards/assets/sRGB-v2-magic.icc`

A minimal, accurate sRGB (IEC 61966-2.1) ICC v2 monitor profile (736 bytes), embedded as the
`/DestOutputProfile` of the PDF/A `GTS_PDFA1` OutputIntent (§14.11.5) so that device-RGB colour is
well-defined in produced PDF/A files.

- **Source:** [Compact ICC Profiles](https://github.com/saucecontrol/Compact-ICC-Profiles) by
  Clinton Ingram (saucecontrol), file `profiles/sRGB-v2-magic.icc`.
- **License:** **CC0 1.0 Universal** — a public-domain dedication, free of restrictions on
  distribution and use.
- ICC header verified: signature `acsp`, device class `mntr`, data colour space `RGB `.

No CMYK profile is bundled: the freely available ones (e.g. eciCMYK) are vendor-copyrighted and do
not meet this project's CC0/permissive bar for committed assets. Supply your own at run time — see
`corpus/prismpdf-pdfa/coverage-gaps.md`.

## 3. Generated tables derived from third-party data

### 3.1 `crates/pdf-fonts/src/standard_metrics.rs`

Standard-14 glyph advance widths (§9.6.2.2), generated by
[`tools/gen_standard_metrics.py`](./tools/gen_standard_metrics.py) and committed so that the build
needs no network. Derived from:

- **Adobe Core14 AFM metrics**, via the copies bundled with
  [Apache PDFBox](https://github.com/apache/pdfbox) at
  `pdfbox/src/main/resources/org/apache/pdfbox/resources/afm` — PDFBox is **Apache-2.0**; Adobe
  publishes the Core14 AFM metrics for redistribution.
- **Adobe Glyph List** (glyph name → Unicode), from
  [adobe-type-tools/agl-aglfn](https://github.com/adobe-type-tools/agl-aglfn) — **BSD-3-Clause**.

The generated file contains advance widths only: factual font metrics, not the font programs
themselves. The Standard-14 fonts are never embedded by Prism PDF.

## 4. Cargo dependencies

Every crate resolved through Cargo is checked by `cargo deny check` against the allow-list in
[`deny.toml`](./deny.toml), which admits only permissive licenses (MIT, Apache-2.0,
Apache-2.0 WITH LLVM-exception, BSD-2/3-Clause, ISC, Zlib, Unicode-3.0, Unicode-DFS-2016). The
authoritative, resolved list for a given build is:

```bash
cargo deny check licenses
cargo tree --workspace --edges normal    # the graph those licenses cover
```

Dependencies are not enumerated here by hand: a hand-copied list goes stale on the next
`cargo update`, whereas the commands above are always current.
