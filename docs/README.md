# docs/

What lives here, and who each file is for.

This directory holds **contracts, indexes and recorded measurements**. It carries no project
status: for what shipped read [`../CHANGELOG.md`](../CHANGELOG.md), for what is next
[`../ROADMAP.md`](../ROADMAP.md), for how the engine is built [`../DESIGN.md`](../DESIGN.md), and
for the working rules [`../AGENTS.md`](../AGENTS.md).

## Contracts — consuming Prism PDF from outside

Every language binding lives in its own repository and links against the C ABI. These three files
are that boundary's contract; changing the boundary means changing them in the same commit.

| File | For you if you are… |
|---|---|
| [`ABI.md`](ABI.md) | writing C against `prismpdf.h`, or porting the ABI — status codes, ownership tables, collection conventions, versioning policy |
| [`BINDINGS.md`](BINDINGS.md) | starting a binding in a new language — object model, naming rules, the conformance suite every binding ports |
| [`native-artifacts.md`](native-artifacts.md) | packaging a binding — what the per-tag prebuilt bundle contains and what may be relied on |

## Working on the engine

| Path | What it is |
|---|---|
| [`spec-map.md`](spec-map.md) | index from an ISO 32000 section number to the crate that owns it — start here to find the code behind a clause |
| [`rfc/`](rfc/README.md) | where to obtain the ISO and PDF Association specifications, and the filenames to save them under. The documents themselves are **not committed** |

## Recorded baselines

[`baselines/`](baselines/) holds measurements, not targets. Each file is regenerated by the test
that owns it, and is updated when the numbers move *and you understand why*.

| File | Owning test | Re-run with |
|---|---|---|
| [`baselines/benchmark.md`](baselines/benchmark.md) | Criterion targets on `pdf-document` and `pdf-layout` | `cargo bench -p prismpdf-document --bench document_operations` |
| [`baselines/conformance.md`](baselines/conformance.md) | `crates/pdf/tests/conformance_corpus.rs` (veraPDF oracle) | manual — it needs the third-party PDF/A corpus, so it is not a CI gate |
| [`baselines/verify.md`](baselines/verify.md) | `crates/pdf/tests/verify_base.rs` (five-validator panel) | `cargo test -p prismpdf --test verify_base -- --nocapture` |
